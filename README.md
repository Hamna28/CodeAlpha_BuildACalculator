# 🧮 Fully Functioning Calculator

A modern and responsive calculator built using **HTML, CSS, and JavaScript**. This project combines a clean UI/UX design inspired by a real-life calculator with fully functional arithmetic operations and interactive user controls.

## 📸 Preview

The calculator features a dark, modern interface with a digital-style display, responsive buttons, smooth interactions, and a clean layout.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Percentage calculations
* 🧹 All Clear (`AC`) functionality
* ⌫ Delete (`DEL`) functionality
* 🔄 Real-time display updates
* ⌨️ Keyboard support
* 📱 Responsive design
* 🎨 Modern calculator-inspired UI/UX
* ✨ Smooth button interactions and hover effects

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling, layout, responsiveness, and UI design
* **JavaScript** – Calculator logic and functionality

## ⌨️ Keyboard Support

The calculator can also be controlled using your keyboard.

| Key            | Function                  |
| -------------- | ------------------------- |
| `0–9`          | Enter numbers             |
| `+`            | Addition                  |
| `-`            | Subtraction               |
| `*`            | Multiplication            |
| `/`            | Division                  |
| `Enter` or `=` | Calculate result          |
| `Backspace`    | Delete the last character |
| `Escape`       | Clear the calculator      |
